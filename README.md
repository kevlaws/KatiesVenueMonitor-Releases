# Katie's Venue Monitor — downloads

Windows installer releases for Katie O'Brien's Irish Taverns' venue monitoring app.

[Download the latest release](https://github.com/kevlaws/KatiesVenueMonitor-Releases/releases/latest)

Install on the Windows server running Katies. Keep the existing installation folder when upgrading, then refresh the website on your phone. Version 0.5.1 adds **Check for updates / Install update** in Katies Server Control.

This repository contains release information and installer downloads. The application's source repository is private. No venue data, accounts, passwords or server API keys are included in these releases.
